자주 묻는 질문

미리 풀어드릴게요

사주를 하나도 몰라도 되나요?

네. 실제 명리학자가 만든 전용 엔진이 계산과 해석을 하고, AI가 리포트를 씁니다. 알려드리는 순서대로만 따라오시면 됩니다. 20대부터 70대까지 함께하고 있고, 70세 어머님도 수강 중이십니다. 나이보다 끝까지 해보시려는 마음이 더 중요합니다.

프로그램 사용에 추가 비용이 드나요?

루월당에 내는 추가 비용은 없습니다. 전용 프로그램은 수강료에 전부 포함이고 평생 사용·계속 업데이트됩니다. PDF를 API로 자동 제작하거나 스레드 자동화(추후)를 쓸 때 API 비용이 들 수 있는데, 이는 외부 사이트에 내는 것이며 무료 방식만 쓰면 들지 않습니다.

결제는 어떻게 하나요?

현재는 계좌이체만 가능합니다. 신청 버튼을 누르시면 입금 계좌를 안내해 드리고, 입금 후 카카오톡으로 알려주시면 확인해 드립니다. 카드 결제는 승인 심사 중이며, 카드 결제 시에는 할인이 적용되지 않습니다.

피드백은 얼마나 받을 수 있나요?

횟수 제한 없이, 한 번 수강하면 평생입니다. 기수가 끝나도 질문은 계속 받습니다. 다만 수강생이 늘면 제가 먼저 한 분씩 챙겨드리긴 어렵습니다. 물어보시는 분이 가장 빨리 갑니다.

스레드 자동화는 지금 쓸 수 있나요?

준비 중이며 추후 배포 예정입니다. 배포되면 수강생은 추가 비용 없이 바로 사용하실 수 있습니다.

정원이 정해져 있나요?

3기는 10명 제한입니다. 정원이 마감되면 조기 종료되며, 4기부터 110만원으로 인상될 예정입니다.
